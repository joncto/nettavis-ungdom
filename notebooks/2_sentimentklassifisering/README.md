## Kodebok for korpus, konkordanser og kollokasjoner

`sentiment_etter_rekkevidde.py` er en interaktiv kodebok for å beregne og visualisere resultater fra sentimentklassifisering.

## Avhengigheter

Kjøring av kode boken forutsetter:
- ptyhon 3.10 eller seinere
- `uv`

## Åpne kodeboka

Åpne terminal og kjør:

```
uv venv
uv run marimo edit --sandbox sentiment_etter_rekkevidde.py
```

Kodeboka vil åpne seg i nettleseren og er klar for bruk.
